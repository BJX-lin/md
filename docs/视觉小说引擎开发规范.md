# 0 前言与术语

## 0.1 为什么是"军工级"

游戏开发同样可以执行工程化纪律。本文档借用航空航天软件（DO-178C 思想）的工程实践，
落到游戏领域的可执行版本：

| 军工概念 | 游戏落地 |
|---|---|
| 可追溯性 | 每个功能/缺陷都能定位到剧本节点、提交记录、测试用例 |
| 确定性 | 给定存档 + 输入序列，演出结果可复现（禁止裸随机未播种） |
| 防御式编程 | 资源缺失、存档损坏、空指针全部有降级路径，不崩溃 |
| 预算制 | 帧率、内存、加载时间、包体都有量化上限，超限即缺陷 |
| 全生命周期 | 需求（策划案）→ 设计（本文档）→ 实现 → 验证（测试）→ 发布（清单）→ 维护 |

## 0.2 术语表

| 术语 | 定义 |
|---|---|
| VN / AVG | 视觉小说（Visual Novel），本文特指文字冒险分支叙事游戏 |
| 节点（Story Node） | 剧本中的最小叙事单元（一段演出 + 可选的选项/跳转） |
| 快照（Snapshot） | 某一时刻的完整游戏状态，用于存档/回滚/测试 |
| 演出（Directive） | 剧本指令：背景、立绘、音效、特效、等待等 |
| 阻塞（Blocking） | 演出暂停剧情推进等待玩家输入或演出结束 |
| 已读（Read） | 文本曾被完整展示过的标记，用于跳过功能 |
| 降级路径（Fallback） | 资源缺失/异常时的次级呈现方案（占位图/静音/错误页） |
| 周目（Playthrough） | 一次从新游戏到结局的完整流程 |

# 1 军工级质量标准总纲

## 1.1 五条铁律（违反任何一条 = 代码不通过评审）

### T1 类型安全
```gdscript
# ❌ 禁止：公开 API 使用无类型/Variant
func set_data(key, value) -> void: ...

# ✅ 正确：全静态类型
func set_num(key: StringName, value: int) -> void: ...
```
- 所有公开函数参数/返回值必须有显式类型注解。
- `Variant` 只允许出现在与外部数据交界处（JSON 解析、存档反序列化），且必须在边界处完成类型验证与转换（见 6.3）。
- 字典访问 `d.get()` 的返回值在使用前必须显式转换：`var n := int(d.get("hp", 0))`。

### T2 无警告编译
- 项目开启「警告视为错误」：编辑器设置 → GDScript → `Treat Warnings as Errors`。
- 允许的例外：`@warning_ignore` 白名单仅限 3 类，且必须同一行注明理由：
```gdscript
@warning_ignore("integer_division")  # 剧情数值允许向下取整
var half := total / 2
```

### T3 单一数据源（Single Source of Truth）
- 一切可存档的运行时状态**只**存在于 `GameState` 单例。
- UI、立绘、音频**不得持有**会改变剧情走向的状态；它们只能缓存展示层状态（如"当前显示第几个字"）。
- 任何写状态的入口只能经 `GameState.set_*` 系列函数（带范围钳制与变更信号）。

### T4 失败可恢复
- 任何 `FileAccess.open()` / `load()` / `JSON.parse_string()` 的失败都必须有处理分支。
- 启动路径（开屏→标题）零外部依赖：缺任何资源也必须能进标题。
- 资源查找统一走 `ResourceLoader.exists()` 预检，禁止让引擎打 ERROR 日志。

### T5 全程可复现（确定性）
- 剧情内随机数必须显式播种：`var rng := RandomNumberGenerator.new(); rng.seed = 固定种子`。
- 禁止在 `_process` 中用 `randf()` 影响剧情状态。
- 演出动画用 `_t += delta` 的基于时间的确定性推进，不依赖帧数。

## 1.2 度量红线（静态分析必查）

| 度量 | 红线 | 说明 |
|---|---|---|
| 单函数行数 | ≤ 60 行 | 超过必须拆分 |
| 圈复杂度 | ≤ 10 | 超过用查表/状态机/polymorphism 重构 |
| 单文件行数 | ≤ 800 行 | 超过按职责拆模块 |
| 单例直接访问 | 白名单制 | 见 2.3 依赖规则 |
| 嵌套深度 | ≤ 4 层 | match 内嵌 if 内嵌 for 即超限 |
| 每公开函数注释 | 必填 | 格式见 1.3 |
| 每模块测试覆盖 | 核心 ≥ 80% | 见 10.6 |

## 1.3 函数注释规范（Doxygen 风格）

```gdscript
## 设置数值变量（带范围钳制，超限部分静默丢弃）。
## 前置：key 必须存在于 Cfg.NUM_RANGE；value 为整数。
## 后置：nums[key] 被钳制到合法区间；若值变化则发出 var_changed。
## 错误：非法 key 触发 assert（仅调试构建）；release 构建静默忽略。
func set_num(key: StringName, value: int) -> void:
```

# 2 工程架构规范

## 2.1 目录结构（通用 VN 工程）

```
project/
├── project.godot          # 引擎配置（唯一由编辑器生成的配置）
├── main.tscn              # 入口场景：只挂 App 根节点
├── autoload/              # 全局单例（加载顺序必须写入文档）
│   ├── app.gd             #  App：界面路由/主题/全局输入（唯一做 UI 切换的层）
│   ├── cfg.gd             #  Cfg：常量、数值范围、角色表、阈值（无运行时状态）
│   ├── game_state.gd      #  GameState：唯一可存档状态源
│   ├── story_engine.gd    #  StoryEngine：剧本解析 + 执行器
│   ├── save_manager.gd    #  SaveManager：存档/读档/设置/周目数据
│   ├── audio_manager.gd   #  AudioManager：BGM/环境/音效/语音
│   ├── art_cache.gd       #  ArtCache：贴图缓存与生命周期
│   ├── loc.gd             #  Loc：本地化（可选）
│   └── event_bus.gd       #  EventBus：模块间解耦事件（可选）
├── src/
│   ├── ui/                # 界面（推荐纯代码构建；复杂界面用 .tscn）
│   ├── art/               # 演出层（背景/立绘/特效）
│   └── systems/           # 打字机/历史回放/自动跳过等子系统
├── story/                 # 剧本（.vn DSL 或 .json，见第 5 节）
├── assets/
│   ├── bg/ sprites/ audio/ ui/ fonts/ video/
└── tools/                 # 校验器/打包/生成器（Python 或 GDScript）
```

## 2.2 自动加载单例职责边界

| 单例 | 职责 | 禁止 |
|---|---|---|
| App | 界面路由、主题构建、全局输入分发 | 持有剧情状态 |
| Cfg | 常量与配置表 | 任何运行时可变状态 |
| GameState | 变量/标记/枚举/道具/线索/周目 | UI 逻辑、文件 IO |
| StoryEngine | 解析 .vn、执行指令、选项、跳转 | 直接操作 UI（只能发信号） |
| SaveManager | 序列化/反序列化/校验和/原子写入 | 直接改 GameState 之外的全局 |
| AudioManager | 通道管理、播放、音量 | 剧情逻辑 |
| ArtCache | 贴图加载/缓存/预取/释放 | 剧情逻辑 |
| Loc | 文本 key → 译文 | 剧情逻辑 |
| EventBus | 模块解耦信号 | 承载业务状态 |

**单例不得互相循环依赖**：依赖图必须单向（GameState → Cfg；StoryEngine → GameState/Cfg/Audio；UI → 全部）。

## 2.3 依赖规则（DI 思想）

1. 允许：UI 读 GameState、调用 StoryEngine.advance()。
2. 禁止：StoryEngine 直接持有 UI 节点引用；StoryEngine 只能发信号（`line_ready` / `choices_ready` / `effect_requested`），由 UI 订阅。
3. 禁止：任意脚本直接 `load()` 大贴图；必须经 `ArtCache.get_tex()`。
4. 单例访问白名单：`Cfg`/`GameState`/`StoryEngine`/`SaveManager`/`AudioManager`/`ArtCache` 可被任意模块访问；其余单例访问需评审豁免。

## 2.4 场景树分层（演出舞台）

```
Main (Node)
├── UI (CanvasLayer, layer=10)     # 对话框/选项/顶栏/菜单
│   ├── DialogueBox
│   ├── ChoicePanel
│   └── MenuOverlay
├── Stage (Control, 全屏)          # 舞台层（从下到上）
│   ├── BGLayer                    # 背景（含切换渐变）
│   ├── ActorLayer                 # 立绘（槽位布局）
│   └── FXLayer                    # 特效（震屏/闪白/雾）
└── System (CanvasLayer, layer=20) # 通知/加载遮罩/截图
```

分层的意义：**对话 UI 永不遮挡舞台的关键信息；特效不干扰可点击区域**。
所有层用 `mouse_filter` 精确控制点击穿透（`IGNORE` 让舞台可点，`STOP` 挡住下层）。

| 对象 | 规范 | 示例 |
|---|---|---|

# 3 GDScript 4 语法速查（VN 视角精选）

## 3.1 静态类型与类型推断

```gdscript
var n := 10                        # 推断 int
var names: Array[String] = []      # 类型化数组
var table: Dictionary = {}         # 字典（4.4+ 可用 Dictionary[String, int] 类型化）
var tex: Texture2D = null          # 可空对象类型
const SPEED: float = 1.5
```

**军规**：`:=` 推断只能用于右侧类型确定的表达式（字面量、new、类型化函数返回值）。
右侧是 Variant 来源（`get_meta()` / `d.get()` / 数组下标取未类型化数组）时禁止 `:=`，
必须显式标注或转换，否则触发 T2 警告（"inferred from Variant"）。

## 3.2 导出注解（编辑器可配置）

```gdscript
@export var speed: float = 1.0
@export_range(0.0, 10.0, 0.1) var volume: float
@export_enum("Morning", "Noon", "Night") var phase: int
@export_file("*.png") var portrait: String
@export_category("Audio")
```

## 3.3 @onready 与场景引用

```gdscript
@onready var label: Label = $Panel/Text/Label
@onready var stage := %Stage          # unique_name_in_owner 节点用 %
```

## 3.4 class_name 与内部类

```gdscript
class_name DialogueBox extends PanelContainer

class LineData:                      # 内部类作数据载体
    var who: String
    var text: String
```

## 3.5 信号、Callable、Lambda

```gdscript
signal line_ready(line: Dictionary)
signal finished(ending_id: String)

button.pressed.connect(_on_pressed)
button.pressed.connect(func(): print("clicked"))        # lambda
cb.call_deferred()                                       # 安全时序调用
var bound := _on_item.bind("apple")                      # 预绑定参数
```

**军规**：动态生成的 UI 节点在释放前必须断开与外部对象的连接（见 8.6 内存泄漏）。

## 3.6 await 与协程陷阱

```gdscript
await get_tree().create_timer(1.0).timeout   # 等待 1 秒
await tween.finished                          # 等待动画结束
```
- `await` 之后的代码**不是同一帧**执行，中间状态可能被外部修改——必须重新读取状态。
- 信号处理函数若被 await 挂起，期间同名信号再次触发会告警；高频信号（如 `_process` 级）禁止 await。

## 3.7 match 与 enum

```gdscript
enum GoreLevel { OFF, MILD, FULL }

match level:
    GoreLevel.OFF:
        return
    GoreLevel.MILD:
        amount *= 0.5
    _:
        pass
```

## 3.8 const 表（只读数据驱动）

```gdscript
const NUM_RANGE := {
    "sanity": [0, 100],
    "trust_heroine": [-50, 50],
}
```
`const` 字典只读；运行时状态表必须放 GameState。

## 3.9 Resource 与自定义资源（类型安全的剧本格式）

```gdscript
class_name StoryLine extends Resource
@export var speaker: String
@export_multiline var text: String
@export var effects: Dictionary = {}
```

## 3.10 常用内建速查

| 需求 | 写法 |
|---|---|
| 字符串格式化 | `"第 %d 章 %s" % [n, title]` |
| 三元 | `var x := a if cond else b` |
| 类型判断 | `if node is Control:` |
| 安全转换 | `var t := obj as Texture2D`（失败返回 null） |
| 范围钳制 | `clampi(v, lo, hi)` / `clampf` |
| 数值插值 | `lerpf(a, b, t)` |

# 4 节点选型与使用手册

> 原则：**能用一个节点的组合解决，绝不新开节点类型**；UI 优先纯代码构建（可审查、可测试、无场景解析开销），
> 只有复杂动画组合才用 .tscn + AnimationPlayer。

## 4.1 Control 体系

| 节点 | 用途（VN 场景） | 关键属性 | 性能/陷阱 |
|---|---|---|---|
| Control | 所有 UI 基类 | `set_anchors_preset(PRESET_*)`、`mouse_filter` | 布局全靠锚点+offset；禁止手写绝对像素坐标 |
| Label | 名字牌、按钮文字、提示 | `text`、`horizontal_alignment`、`autowrap_mode` | 大段文本勿用（不能滚动） |
| RichTextLabel | **对话框正文（首选）** | `bbcode_enabled`、`visible_characters`（打字机）、`scroll_active` | 打字机核心；关闭滚动与交互以省性能 |
| LineEdit | 命名/输入 | `max_length`、`placeholder_text`、`text_submitted` | 注意：对齐属性叫 `alignment`，**没有** `horizontal_alignment` |
| TextEdit | 长文本输入/日志查看 | `editable`、`syntax_highlighter` | VN 中极少需要 |
| Button | 选项、菜单按钮 | `pressed` 信号、stylebox 主题 | 触屏最小 48×48；`focus_mode = NONE` 防抢焦点 |
| PanelContainer | 对话框/菜单面板外框 | `add_theme_stylebox_override("panel", sb)` | 子节点按 content_margin 内缩，纹理铺满需用兄弟节点 |
| MarginContainer | 页边距容器 | `add_theme_constant_override("margin_left", 56)` | 布局首选而非手调 offset |
| HBox/VBox/GridContainer | 线性/网格布局 | `separation`、`alignment`、`size_flags_*` | `SIZE_EXPAND_FILL` 控制拉伸 |
| ScrollContainer | 历史回放、菜单滚动 | `scroll_deadzone`、`follow_focus` | 触屏惯性滚动默认开启 |
| CenterContainer | 居中（标题、选项区） | — | 包裹内容自动居中 |
| AspectRatioContainer | 立绘/视频等比例 | `ratio` | 防止拉伸变形 |
| TextureRect | 背景图、贴图展示 | `expand_mode`、`stretch_mode`（COVER/CENTERED） | 大图 COVER 裁切，KEEP_ASPECT_CENTERED 保比例 |
| ColorRect | 遮罩、闪白、压暗 | `color`、`mouse_filter` | 闪屏用 tween 改 modulate:a 而非重建 |
| NinePatchRect | 九宫格边框（对话框底） | `patch_margin_*` | 比 StyleBoxTexture 少一层抽象 |
| ProgressBar | 理智/好感度条 | `min_value`/`max_value`/`value` | 满刻度应取"单周目可达值"而非理论上限 |
| Slider | 音量等设置 | `value_changed` | 拖动高频信号，注意节流 |
| SubViewport | 全屏后处理 | — | **VN 禁用**：2D 合成用 CanvasItem 叠加即可 |

## 4.2 动画与时序

| 节点/类 | 用途 | 要点 |
|---|---|---|
| Tween（create_tween） | 演出微动画（淡入、位移、呼吸） | 链式：`tween_property().set_trans().set_ease()`；`parallel()` 并行；UI 用 `Tween.TRANS_SINE/EASE_OUT` |
| AnimationPlayer | 过场 CG、复杂骨骼动画 | 只用于预定义动画；程序化演出用 Tween |
| Timer | 限时选项、超时跳转 | `one_shot = true`；用 `start()` 而非场景常驻 |

**军规**：Tween 一律 `create_tween()` 局部创建并挂到宿主节点，宿主释放时自动终止；
禁止在全局容器创建长命 Tween（内存泄漏高发区）。

## 4.3 音频

| 节点 | 用途 | 要点 |
|---|---|---|
| AudioStreamPlayer | 单条播放 | BGM/环境音各一个常驻；音效用对象池（8 路轮换） |
| AudioServer 总线 | 分类音量（Music/Amb/SFX/Voice） | `AudioServer.add_bus()` 动态建总线；设置页调 `set_bus_volume_db` |
| AudioStreamWAV / OGG | 音频资源 | 手机端 22050Hz 单声道 OGG 性价比最高 |
| AudioStreamPlayback | 高级控制 | 一般不需要 |

## 4.4 数据与 IO

| 类 | 用途 | 军规 |
|---|---|---|
| FileAccess | 文件读写 | `open()` 返回 null 必须处理；写后用 `flush()` |
| DirAccess | 目录遍历/建目录 | `make_dir_recursive_absolute()` 建存档目录 |
| JSON | 存档/剧本（JSON 格式） | `parse_string()` 结果必须 `is Dictionary` 验证；写用 `stringify(d, "\t")` |
| ConfigFile | .cfg 读写 | 少用；项目配置直接读 ProjectSettings |
| HashingContext | SHA256（存档签名/完整性） | `ctx.start(HASH_SHA256) → update(data) → finish().hex_encode()` |
| ResourceLoader | 资源加载 | `exists()` 预检；大图 `load_threaded_request/get` 后台加载 |
| Image / ImageTexture | 运行时生成贴图 | 程序化占位图、截图缩略图 |

## 4.5 输入

| 处理层级 | 用途 | 顺序 |
|---|---|---|
| `_gui_input(event)` | 控件自身点击 | 最先 |
| `_unhandled_input(event)` | 全局：点击推进对话、跳过 | 其次 |
| `_input(event)` | 强制优先（快捷键） | 最后手段，尽量不用 |

- 触屏判断：`event is InputEventScreenTouch and event.pressed`
- 鼠标/触屏统一：工程设置开 `emulate_mouse_from_touch`
- **军规**：演出阻塞（`blocked` 标志）时，点击推进必须被吞掉，防止玩家点穿弹出层。

## 4.6 系统

| 需求 | 写法 |
|---|---|
| 锁帧 | `Engine.max_fps = 60`（Cfg._ready） |
| 垂直同步 | `DisplayServer.window_set_vsync_mode(VSYNC_ENABLED)` |
| 平台判断 | `OS.get_name() in ["Android", "iOS"]` |
| 时间 | `Time.get_ticks_msec()`（性能计时）；`Time.get_datetime_string_from_system()`（存档时间戳） |
| 随机（确定性） | `var rng := RandomNumberGenerator.new(); rng.seed = X` |

# 5 数据驱动剧本规范

## 5.1 三种剧本载体选型

| 载体 | 优点 | 缺点 | 适用 |
|---|---|---|---|
| 自定义 DSL（.vn 文本） | 人类可写、diff 友好、git 协作最佳 | 需要自己写解析器 | **首选** |
| JSON | 工具生成方便、无解析器 | 不可手写、无注释、diff 差 | 本地化表、配置表 |
| Godot Resource | 类型安全、编辑器可视化 | 二进制 diff 差、协作冲突 | 需要编辑器工作流时 |

**推荐组合**：剧本用 DSL；变量/角色/阈值表用 const 字典（GDScript 内）；本地化用 CSV/JSON。

## 5.2 剧本节点 Schema（字段表）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| id | string | ✓ | 全局唯一节点 id（snake_case 分层） |
| bg | string | | 背景 id + 变体（`bg classroom night`） |
| bgm / amb / sfx | string | | 音频 id |
| fx | string[] | | 特效列表（name + strength） |
| actors | array | | `[{who, emo, pos}]` 立绘指令 |
| speaker | string | | 说话人（角色表 key；空 = 旁白） |
| text | string | | 台词（支持插值，见 5.6） |
| choices | array | | 选项（见 5.3） |
| effects | dict | | 进入节点即生效的数值效果 |
| next | string | | 无选项时的后继节点 |
| timeout | float | | 限时跳转秒数（可选） |
| conditions | string | | 节点级显示条件（可选，见 5.4） |

## 5.3 选项 Schema

```json
{
  "text": "选项文本（支持插值）",
  "target": "node_id",
  "effects": {"trust_heroine": 1},
  "cond": "trust_heroine >= 5",       // 不满足则隐藏
  "lock": "item:key_archive",         // 不满足则灰显（显示需求提示）
  "hint": "需要：档案室钥匙"
}
```

## 5.4 条件表达式 EBNF

```ebnf
expr      := or_expr
or_expr   := and_expr { "or" and_expr }
and_expr  := unary { "and" unary }
unary     := ["!"] atom
atom      := comparison | flag | item | clue | state | special | "(" expr ")"
comparison:= ident cmpop integer
cmpop     := ">=" | "<=" | "==" | "!=" | ">" | "<"
ident     := NUM_RANGE 中的变量名 | "chapter" | "cycles" | "gore" | "ending"
flag      := "flag_" 标识符
item      := "item:" 道具id
clue      := "clue:" 线索id
state     := "state:" 键 ("==" | "!=") 值 ["|" 值]*
special   := "visited:" 节点id | "death:" 角色
```

实现注意：求值器必须是**纯函数**（入参=表达式+只读状态），可独立单元测试。

## 5.5 效果指令集

| 指令 | 语义 | 示例 |
|---|---|---|
| `set` | 数值增减 | `@set sanity -5` |
| `flag` | 布尔标记 | `@flag saw_photo` |
| `state` | 枚举状态 | `@state heroine_affection high` |
| `item` | 道具加减 | `@item +item_letter` |
| `clue` | 线索解锁 | `@clue clue_diary` |
| `goto` / `ending` / `return` | 控制流 | `@ending auto`（按权重判定） |

## 5.6 文本插值语法

```
{num:sanity}        数值
{item:item_ring}    道具名
{name:heroine}      角色显示名
{pname}             玩家自定义名
{if 条件?真值|假值}  条件文本
```

## 5.7 本地化规范

- 文本 key：`ch1_scene2_line07`（剧本节点 id + 行序）。
- 剧本内写 key，Loc 查表替换；无译文回退源语言。
- 占位符独立于语序：`"你获得了 {item}。"` → 译文 `"You obtained {item}."`。
- 字体必须同时覆盖源语言与目标语言字形（CJK 用大字符集字体，Latin 扩展同族）。
- 对话人名框宽度按最长译文自适应，禁止写死。

# 7 视觉小说专属系统实现规范

## 7.1 打字机（Typewriter）

```gdscript
## 每帧推进 visible_characters；点击 = 立即完成；再点 = 下一句。
func _process(delta: float) -> void:
    if not _typing: return
    _acc += delta
    if _acc >= SaveManager.text_delay():
        _acc = 0.0
        _shown += 1
        text_label.visible_characters = _shown
        if _shown % 3 == 0:
            AudioManager.play_blip(_cur_who)      # 每 3 字一个打字声
        if _shown >= _full_len:
            _typing = false
            continue_hint.visible = true
```

军规：
- 打字速度四档（0.075 / 0.045 / 0.024 / 0.008 s/字），设置页可调。
- 长句必须限制单次最大字符数（如 120 字分页），防止 RichTextLabel 排版抖动。
- `bbcode_enabled` 时 `visible_characters` 对富文本标签的计数有边界情况，需用纯文本长度预计算。

## 7.2 历史回放（Backlog）

- 结构：`history: Array[{who, text, style}]`，追加时封顶（如 400 条，`pop_front`）。
- UI：ScrollContainer + VBoxContainer，动态生成 Label；只生成可视范围（虚拟列表，超过 200 条必须做）。
- 回放打开时不暂停剧情（允许边看边继续）；关闭时滚动位置不重置（用户体验）。

## 7.3 自动 / 跳过（已读）

```gdscript
## 已读标记：read_set: Dictionary（节点id + 文本哈希 → true）
func _mark_read(line: Dictionary) -> void
## 跳过模式：只跳已读文本；新文本自动降速回正常
func _skip_step() -> void:
    if _cur_is_read:
        advance()          # 已读 → 秒跳
    else:
        _toggle_skip()     # 未读 → 退回普通推进
```

- 跳过中禁止触发 `play_blip`（省 CPU 与刺耳）。
- 自动模式：句子完成后再等 `auto_speed` 秒（设置项），点击立即打断。

## 7.4 选项锁与条件显示

- 三态：正常显示 / `cond` 不满足隐藏 / `lock` 不满足灰显（显示 `hint` 需求文字）。
- 全部选项被条件过滤后为空 → 引擎自动走 `next`（剧本校验器必须警告这种节点）。

## 7.5 分支变量与结局判定

- 结局判定必须是**纯函数**：`determine_ending() -> String`，入参只有 GameState。
- 权重表（config 内声明）：
```gdscript
const ENDING_WEIGHTS := {
    "ending_true": {"min": {"affection": 80, "truth": 60}, "flags": ["key_evidence"]},
    "ending_normal": {"min": {"affection": 40}},
}
```
- 判定优先级自上而下，未命中走默认结局；判定函数必须有单元测试覆盖全部边界。

## 7.6 画廊 / 成就 / 周目

- 跨周目数据独立于周目快照（`persistent` 字典），单独文件 `user://meta.json`。
- 解锁时机与剧情节点解耦：剧情只 `unlock_gallery(id)`，UI 订阅事件弹提示。

## 7.7 演出阻塞队列

- 所有需要"演完再继续"的指令（`wait` / 标题卡 / 名单卡 / 过场）走统一阻塞队列：
  `blocked = true → 演出结束信号 → unblock → engine.advance()`。
- 队列必须有看门狗：超过预算时长（如 30s）强制解锁，防止某个演出卡死整个游戏。

# 8 手机端适配与性能预算

## 8.1 分辨率与拉伸

```ini
[display]
window/size/viewport_width=1280
window/size/viewport_height=720
window/stretch/mode="canvas_items"
window/stretch/aspect="keep"        # 等比留边，绝不拉伸变形
window/handheld/orientation=0       # 0=横屏 1=竖屏 4=自动
```

- 布局全部用锚点/容器，禁止绝对坐标；测试三种比例：16:9 / 20:9 / 4:3。

## 8.2 触控规范

- 最小热区 48×48 逻辑像素（约 9mm 物理）。
- 选项间距 ≥ 16px 防误触；文本框高度 ≥ 全屏 28%，点击区域覆盖整框。
- 支持"点击任意处推进"（AVG 标配）；`blocked` 时吞掉点击。

## 8.3 性能预算表（评审必查）

| 指标 | 预算 | 超限处置 |
|---|---|---|
| 帧率 | 稳定 60fps（低端 40fps 可接受） | 视为缺陷，回滚最近提交 |
| 内存峰值 | ≤ 256MB（中端机） | ArtCache 立即执行 release_stale |
| 单张贴图 | 背景 ≤ 2MB（WebP/PNG 压缩后）；立绘 ≤ 1MB | 重压 |
| 常驻贴图集 | ≤ 80MB | 按章释放 |
| 冷启动到标题 | ≤ 3s | 开屏零依赖、懒加载 |
| 存档写盘 | ≤ 50ms | 纯 JSON，无大图入档 |
| 音频内存 | ≤ 15MB | 22050Hz 单声道 OGG |

## 8.4 图片规范

- 背景：设计 1920×1080，发行压到 1376×768 / 256 色量化（暗色题材视觉无损）。
- 立绘：768×768 起，只裁可见区域（上半身），减少 40% 填充面积。
- 禁止 4K 原图直发；禁止动画 GIF（转 APNG 或序列帧 + AnimationPlayer）。

## 8.5 低端机降级

- 特效档位：`fx_quality` 设置（高/中/低）——低档关闭雾、噪点、全屏后处理。
- 后台时自动静音并暂停计时（`NOTIFICATION_APPLICATION_PAUSED`）。

## 8.6 内存泄漏防线（军工级重点）

1. **信号断开**：动态节点 `queue_free()` 前，先断开它对单例信号的所有连接（记录 connect 返回的 Callable，或使用 `owner` 统一清理）。
2. **Tween 生命周期**：绑定宿主节点（`node.create_tween()`），宿主释放自动终止。
3. **缓存上限**：ArtCache/AudioCache 有 LRU 上限；历史回放数组封顶。
4. **单例零残留**：单例不得持有对临时 UI 节点的引用。
5. **泄漏检测**：`ObjectDB.get_instance_count()` 打点对比（进入/退出界面前后），差值超阈值即告警。

# 9 错误处理、日志与防御式编程

## 9.1 日志分级

| 级别 | 用法 | 发布版行为 |
|---|---|---|
| FATAL | 不可恢复（工程损坏） | 弹错误页 + 退出 |
| ERROR | 功能受损但有降级 | 记录 + 降级路径 |
| WARN | 数据异常已自动纠正 | 记录 |
| INFO | 里程碑（载入剧本 n 节点） | 记录 |
| DEBUG/TRACE | 开发诊断 | 编译期剔除 |

统一封装：`Log.error(msg)` 单例，禁止裸 `print()`（print 无级别无开关）。

## 9.2 断言（前置条件）

```gdscript
assert(key in Cfg.NUM_RANGE, "非法数值键: %s" % key)
assert(i >= 0 and i < SLOT_COUNT, "存档槽越界")
```
- `assert` 仅 debug 构建生效，release 自动剥离 → 性能零成本。
- 断言只用于"程序错误"，**不用于**可预期的外部错误（文件缺失等走降级路径）。

## 9.3 降级链（Fallback Chain）

| 资源 | 缺失时降级 |
|---|---|
| 背景图 | 纯色底 + 场景名角标（debug） |
| 立绘 | 代码绘制剪影占位 |
| 音频 | 静音（不报错） |
| 剧本节点 | 跳错误节点（显示"此处缺失"文本） |
| 存档 | 提示损坏 + 允许继续（标记 tampered） |
| 字体 | 系统默认字体（CJK 回退） |

## 9.4 启动路径零依赖

开屏/标题不得依赖任何可能缺失的资源：所有贴图经 `UITex.get_tex()`（缺图返回 null 走程序化绘制），
音频延迟初始化，剧本载入失败也要能进标题并显示错误徽标。

## A.3 GameState

```gdscript
extends Node
## 唯一可存档状态源。所有写操作经本类（钳制 + 变更信号）。

signal var_changed(key: StringName, old_value: int, new_value: int)

var player_name := "玩家"
var nums: Dictionary = Cfg.NUM_DEFAULT.duplicate()
var flags: Dictionary = {}
var items: Array[String] = []

func reset_run(p_name: String) -> void:
    player_name = p_name.strip_edges()
    if player_name.is_empty():
        player_name = "玩家"
    nums = Cfg.NUM_DEFAULT.duplicate()
    flags.clear()
    items.clear()

func get_num(key: StringName) -> int:
    return int(nums.get(key, 0))

func set_num(key: StringName, value: int) -> void:
    if not Cfg.NUM_RANGE.has(key):
        assert(false, "非法数值键: %s" % key)
        return
    var r: Array = Cfg.NUM_RANGE[key]
    var nv := clampi(value, int(r[0]), int(r[1]))
    var old := get_num(key)
    if nv != old:
        nums[key] = nv
        var_changed.emit(key, old, nv)

func add_num(key: StringName, delta: int) -> void:
    set_num(key, get_num(key) + delta)

func apply_effects(fx: Dictionary) -> void:
    for k in fx:
        add_num(StringName(k), int(fx[k]))

func get_flag(key: StringName) -> bool:
    return bool(flags.get(key, false))

func set_flag(key: StringName, value := true) -> void:
    flags[key] = value

func has_item(id: StringName) -> bool:
    return items.has(String(id))

func add_item(id: StringName) -> void:
    var s := String(id)
    if not items.has(s):
        items.append(s)

func determine_ending() -> String:
    for rule in Cfg.ENDING_RULES:
        var ok := true
        for k in rule["min"]:
            if get_num(StringName(k)) < int(rule["min"][k]):
                ok = false
                break
        if ok:
            return String(rule["id"])
    return "ending_normal"

func to_dict() -> Dictionary:
    return {"player_name": player_name, "nums": nums.duplicate(),
            "flags": flags.duplicate(), "items": items.duplicate()}

func from_dict(d: Dictionary) -> void:
    player_name = String(d.get("player_name", "玩家"))
    nums = Cfg.NUM_DEFAULT.duplicate()
    for k in d.get("nums", {}):
        if Cfg.NUM_RANGE.has(k):
            nums[k] = int(d["nums"][k])
    flags = (d.get("flags", {}) as Dictionary).duplicate()
    items.clear()
    for i in d.get("items", []):
        items.append(String(i))
```

## A.4 StoryEngine（极简 DSL：`==` 节点 / `@set` / `@bg` / `* 选项 -> 目标` / `角色: 台词`）

```gdscript
extends Node
## 剧本执行器。只发信号，不碰 UI。

signal line_ready(line: Dictionary)
signal choices_ready(choices: Array)
signal scene_requested(kind: String, a: String, b: String)

const STORY_DIR := "res://story"

var nodes: Dictionary = {}          # id -> Array[Dictionary]
var _cur: Array = []
var _ip := 0
var waiting_choice := false

func _ready() -> void:
    load_all()

func load_all() -> void:
    nodes.clear()
    var dir := DirAccess.open(STORY_DIR)
    if dir == null:
        push_error("剧本目录缺失: " + STORY_DIR)
        return
    for f in dir.get_files():
        if f.ends_with(".txt"):
            _parse_file(STORY_DIR + "/" + f)

func _parse_file(path: String) -> void:
    var txt := FileAccess.get_file_as_string(path)
    var cur_id := ""
    var prog: Array = []
    for raw in txt.split("\n"):
        var s := raw.strip_edges()
        if s.is_empty() or s.begins_with("--"):
            continue
        if s.begins_with("=="):
            if cur_id != "":
                nodes[cur_id] = prog
            cur_id = s.substr(2).strip_edges()
            prog = []
        elif s.begins_with("@set"):
            var parts := s.substr(4).split(" ", false)
            prog.append({"op": "set", "key": parts[0], "delta": int(parts[1])})
        elif s.begins_with("@bg"):
            var parts := s.substr(3).split(" ", false)
            prog.append({"op": "bg", "id": parts[0], "v": parts[1] if parts.size() > 1 else ""})
        elif s.begins_with("*"):
            var body := s.substr(1).strip_edges()
            var arrow := body.rfind("->")
            prog.append({"op": "choices", "text": body.substr(0, arrow).strip_edges(),
                         "target": body.substr(arrow + 2).strip_edges()})
        else:
            var colon := s.find("：")
            if colon > 0 and colon <= 24 and Cfg.CHARACTERS.has(s.substr(0, colon).strip_edges()):
                prog.append({"op": "say", "who": s.substr(0, colon).strip_edges(),
                             "text": s.substr(colon + 1).strip_edges()})
            else:
                prog.append({"op": "say", "who": "", "text": s})
    if cur_id != "":
        nodes[cur_id] = prog

func start(node_id: StringName) -> void:
    if not nodes.has(node_id):
        push_error("节点不存在: " + node_id)
        return
    _cur = nodes[node_id]
    _ip = 0
    waiting_choice = false
    advance()

func advance() -> void:
    if waiting_choice:
        return
    while _ip < _cur.size():
        var ins: Dictionary = _cur[_ip]
        _ip += 1
        match String(ins.get("op", "")):
            "say":
                line_ready.emit(ins)
                return
            "set":
                GameState.add_num(StringName(ins["key"]), int(ins["delta"]))
            "bg":
                scene_requested.emit("bg", String(ins["id"]), String(ins["v"]))
            "choices":
                waiting_choice = true
                choices_ready.emit([ins])
                return

func pick_choice(choice: Dictionary) -> void:
    waiting_choice = false
    var target := String(choice.get("target", ""))
    if target != "":
        start(StringName(target))
```

## A.5 DialogueBox（打字机最小实现）

```gdscript
class_name DialogueBox extends Control
## 对话框：名字牌 + RichTextLabel 打字机。点击：完成 → 下一句。

var name_label: Label
var text_label: RichTextLabel
var _typing := false
var _full := ""
var _shown := 0
var _acc := 0.0

func _ready() -> void:
    set_anchors_preset(Control.PRESET_BOTTOM_WIDE)
    name_label = Label.new()
    text_label = RichTextLabel.new()
    text_label.bbcode_enabled = true
    add_child(name_label)
    add_child(text_label)
    StoryEngine.line_ready.connect(show_line)

func show_line(line: Dictionary) -> void:
    var who := String(line.get("who", ""))
    name_label.visible = who != ""
    name_label.text = String(Cfg.CHARACTERS.get(who, {}).get("name", who))
    _full = String(line.get("text", ""))
    text_label.text = _full
    text_label.visible_characters = 0
    _shown = 0
    _typing = true

func _process(delta: float) -> void:
    if not _typing:
        return
    _acc += delta
    if _acc >= 0.045:
        _acc = 0.0
        _shown += 1
        text_label.visible_characters = _shown
        if _shown >= _full.length():
            _typing = false

func _unhandled_input(e: InputEvent) -> void:
    var tap := (e is InputEventScreenTouch and e.pressed) \
            or (e is InputEventMouseButton and e.pressed)
    if not tap:
        return
    if _typing:
        text_label.visible_characters = _full.length()   # 点击 = 立即完成
        _typing = false
    else:
        StoryEngine.advance()                             # 再点 = 下一句
```
