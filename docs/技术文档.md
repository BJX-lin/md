## 三、全局单例 API

### 3.1 Cfg（autoload/config.gd）

| 成员 | 说明 |
|---|---|
| `GAME_TITLE` / `GAME_SUBTITLE` / `VERSION` | 游戏名 / 副标题 / 版本号 |
| `NUM_RANGE` | 各数值变量上下限（防截断） |
| `NUM_DEFAULT` | 数值初始值 |
| `NUM_LABEL` | 数值中文名 |
| `NUM_VISIBLE` | 玩家可见四项（真相/理智/回响/关注） |
| `BAR_MAX` | 状态条满刻度（单周目可达值，与上限分离） |
| `ENUM_DEFAULT` | 枚举状态默认值 |
| `CHARACTERS` | 角色表：名字/主色/声线基频 |
| `TH_TRUTH` / `TH_SANITY` | 真相 7 档 / 理智 5 档阈值表 |
| `GoreLevel` | 血腥三档枚举（OFF/MILD/FULL） |
| `TEXT_SPEED_PRESET` | 文本速度预设 |
| `PALETTE` | 全局配色（墨/纸/血/锈/冷/警示/鬼/线） |
| `QQ_ENC` / `QQ_SIG` 等 | 联系方式防篡改编码（HashingContext 校验） |

### 3.2 GameState（autoload/game_state.gd）

状态容器。信号：`var_changed(key, old, new)`、`time_changed(day, minute)`。

**数值**
```gdscript
get_num(key) / set_num(key, v) / add_num(key, delta)
```
**标记与枚举**
```gdscript
get_flag(key) / set_flag(key, value)
get_state(key) / set_state(key, value)
```
**道具与线索**
```gdscript
has_item(id) / add_item(id) / remove_item(id) / item_name(id)
add_clue(id)                      # 同时写入周目图鉴 persistent.clues_seen
```
**剧情时间**
```gdscript
set_story_time(day, minute)       # 绝对设置（@time）
seek_story_time(day, minute, min_adv)  # 单调推进，绝不倒流（@timeat）
advance_time(minutes)             # 相对推进（@advtime）
time_hhmm() / time_phase() / time_display()
```
**章节结算**
```gdscript
settle_chapter_1() .. settle_chapter_4()   # 状态机结算（@settle）
```
**结局**
```gdscript
determine_ending() -> String      # 五结局判定
can_true_end() / can_bittersweet_exchange() / can_destroyer() / can_manager()
_true_end_weight() -> int         # 真结局软权重（满分 14）
record_ending(id)                 # 记录结局+周目+1+最高真相
```
**序列化**
```gdscript
to_dict() / from_dict(d)          # 存档载荷（含 player_name / 场景 / 立绘台面）
```
**其他**
```gdscript
reset_run()                       # 新周目重置（不重置玩家名）
register_loss(who, kind)          # 死亡/失踪登记（@death）
unlock_gallery(id)                # 图鉴解锁（@gallery）
player_name: String               # 玩家自定义主角名（新游戏命名写入）
```

### 3.3 StoryEngine（autoload/story_engine.gd）

`.avg` 剧本 DSL 解析器 + 运行时虚拟机（详见第四节）。

信号：`line_ready` / `choices_ready` / `node_started` / `story_finished` /
`chapter_started` / `effect_requested` / `scene_requested` / `actor_requested` /
`overlay_requested`。

```gdscript
load_all()                        # 载入 story/ 全部 .avg（启动时自动）
parse_file(path) / parse_text(txt, src)
start(node_id)                    # 从某节点开始执行
advance()                         # 推进到下一个需要交互的点
pick_choice(choice)               # 选项结算
padlock_done(success)             # 密码锁结算（跳成功/失败节点）
eval_cond(expr) -> bool           # 条件求值
has_story_node(id) / snapshot() / restore(node_id)
```

### 3.4 SaveSystem（autoload/save_system.gd）

| 函数 | 说明 |
|---|---|
| `autosave()` / `read_autosave()` | 自动槽（章节推进点触发） |
| `save_slot(i)` / `read_slot(i)` / `delete_slot(i)` | 8 个手动槽 |
| `has_any_save()` | 标题"继续"可用性 |
| `build_payload()` | 载荷 = GameState.to_dict + 元信息（版本/时间/预览文本） |
| `_sign` / `_verify` | 存档 SHA256 签名（改档检测，标记 `_tampered`） |
| `load_settings() / save_settings() / set_setting(k, v)` | 设置持久化 |
| `text_delay() -> float` | 文本速度（设置档） |
| `gore_level() -> int` | 血腥档 0/1/2 |
| `load_persistent() / save_persistent()` | 周目数据（结局次数/线索图鉴/循环数/最高真相） |

**设置项**（`user://settings.json`）：`vol_master` / `vol_bgm` / `vol_sfx` /
`text_speed` / `gore` / `screen_shake` / `auto_speed` / `show_fps`。

### 3.5 AudioDirector（autoload/audio_director.gd）

```gdscript
play_bgm(id) / stop_bgm()         # 音乐（单通道）
play_amb(id) / stop_amb()         # 环境音（单通道）
play_sfx(id, vol_scale)           # 音效（8 路复用池，防截断）
play_blip(char_key)               # 打字声（按角色 pitch 变调）
apply_settings(s)                 # 音量设置应用
```

- 加载优先级：`assets/audio/<id>.ogg → .wav → .mp3` → 内置 `_synth()` 静音兜底
- BGM/环境音自动 LOOP；音效 LRU 缓存上限 12 条
- 采样率 22050Hz、单声道、16bit——手机端最小内存占用

### 3.6 ArtCache（autoload/art_cache.gd）

贴图缓存 + 按章生命周期管理：
```gdscript
get_tex(path)                     # 命中缓存直返，否则 load
paths_for_chapter(chapter)        # 章节预取清单（CHAPTER_BG + CHAPTER_CHARS）
release_stale(chapter, keep)      # 释放后面章节不再用的贴图
stats() / clear_all()
```

### 3.7 Integrity（autoload/integrity_manifest.gd）

核心文件 SHA256 自检（`MANIFEST` 常量，由 `tools/gen_integrity.py --write` 生成）。
校验失败仅提示不拦截：`verify() / is_intact() / failed_files() / notice()`。

## 四、剧本 DSL 参考（.avg）

### 4.1 指令速查

| 指令 | 格式 | 说明 |
|---|---|---|
| 节点头 | `== node_id` | 节点开始（唯一） |
| 注释 | `-- 注释` | 忽略 |
| 背景 | `@bg 场景 [变体]` | 切换背景（映射见第七节 BG_MAP） |
| 音乐 | `@bgm id` / `@stopbgm` | BGM 切换/停止 |
| 环境 | `@amb id` / `@stopamb` | 环境音切换/停止 |
| 音效 | `@sfx id [音量]` | 播放音效 |
| 特效 | `@fx 名称 [强度]` | 演出特效（见第六节） |
| 立绘 | `@show 角色 表情 [位置]` / `@hide 角色` / `@clearchars` | 出场/退场/清台 |
| 数值 | `@set 变量 +N\|-N\|=N` | 数值增减 |
| 标记 | `@flag 名 [true\|false]` | 布尔标记 |
| 状态 | `@state 键 值` | 枚举状态 |
| 道具 | `@item +id\|-id` | 获得/移除道具（获得时弹 Toast） |
| 线索 | `@clue id` | 解锁线索（弹 Toast） |
| 死亡 | `@death 角色 方式` | 死亡/失踪登记 |
| 图鉴 | `@gallery id` | 解锁演出图鉴 |
| 大字幕 | `@title 文本` | 居中大字卡（阻塞推进） |
| 名单 | `@roster` | 动态名单演出卡 |
| 提示 | `@note 文本` | 纸条演出卡 |
| 密码锁 | `@padlock 密码 成功节点 [失败节点] 提示` | 数字密码小游戏 |
| 时间 | `@time 天 时:分` / `@timeat 天 时:分 [兜底分]` / `@advtime 分` | 剧情时钟 |
| 等待 | `@wait 秒` | 演出停顿（阻塞） |
| 章节 | `@chapter 数字 标题` | 章节卡（阻塞） |
| 结算 | `@settle 章号` | 章节结算（1~4） |
| 存档 | `@autosave` | 自动存档点 |
| 跳转 | `@goto 节点` / `@ending 结局id\|auto` / `@return` | 控制流 |
| 条件 | `@if 条件` / `@elif` / `@else` / `@endif` | 分支 |
| 选项 | `* 选项文本 -> 目标节点` | 选项；其下缩进 `@` 行为即时效果 |
| 选项条件 | `* [if 条件] 文本 -> 目标` | 不满足隐藏 |
| 选项锁定 | `* [lock 条件] 文本 -> 目标` | 不满足灰显（显示条件提示） |
| 台词 | `角色: 台词` / `角色(表情): 台词` | 说话人须在 Cfg.CHARACTERS |
| 旁白 | 普通行 | 旁白 |
| 强调 | `> 文本` | 旁白强调样式 |

### 4.2 文本插值

```
{pname}                玩家名（主角）
{num:truth}            数值显示
{item:item_page109}    道具名
{name:liangye}         角色名
{if 条件?A|B}          条件文本
```
玩家改名后，正文中的"林昼"自动替换为玩家名。

### 4.3 条件求值

支持 `and` / `or`、`!` 取反。原子：
```
truth>=5 / sanity<40 / trust_liangye>=2     数值比较
flag_xxx / !flag_xxx                         标记
item:item_admin_key / clue:clue_terms        道具 / 线索
state:liangye_end_state==present_anchor      枚举（== 或 !=，支持 | 多值）
ending:true / chapter>=3 / cycles>=1 / gore>=2 / visited:node_id / death:xxx
```

### 5.2 阈值表

**真相（7 档）**：230 异常非错觉 / 460 读懂规则 / 690 待定与删除之别 /
830 校史馆线 / 920 质问补位 / 1150 complete 候选 / 1280 高阶真相。

**理智（5 档）**：80 稳定 / 60 偶发错听 / 40 文本被篡改 / 20 幻视幻听 / 10 选项可能撒谎。

### 5.3 结局判定

| 结局 | 硬条件 |
|---|---|
| 真结局《点名停止》 | truth_state==complete + 两个前置 flag + `flag_rule_terms_complete` + `flag_terminal_broadcast_ready` + 未弃室友 + 梁野可沟通 + **软权重 ≥8**（满分 14：写回名字+2 / 夜间名单+2 / 救沈禾+3 / 梁野信任+2 / 锚点状态+2 / 周叙信任+1 / 陪同+1 / 火灾录像+1 / 林昼状态+1，缺席-2）+ save_route_score ≥100 |
| 遗憾《留堂》 | save_route_score ≥80 + 广播就绪 +（梁野缺席 / 规则不全 / 主动替代 `flag_player_self_substitute`） |
| 毁灭《焚校》 | end_cycle_score ≥7 + 广播就绪 + `flag_chose_end_cycle` |
| 管理员 | control_route_score ≥7（弃室友时 ≥5） |
| 空席《到》 | 以上均不满足（兜底） |

篡改档（`save_tampered`）一律回落空席结局。

## 十四、性能设计要点

- **渲染**：Mobile 后端 + gl_compatibility；MSAA 关闭（纯 2D 合成无需抗锯齿）
- **帧率**：锁定 60fps + 垂直同步（Cfg._ready）
- **贴图生命周期**：ArtCache 按章预取/释放，背景+立绘全常驻会超几百 MB 显存
- **立绘重绘**：待机呼吸动画限 ~14fps，仅故障/流血特效全速重绘
- **音效**：8 路复用池防截断，LRU 缓存限 12 条合成结果
- **文本**：逐字显示按 3 字一帧节流；回想记录封顶 400 条
- **脚本**：无 .tscn 界面（代码构建），启动零场景解析；开场无贴图兜底
- **包体**：音频 OGG 化（48→1.2MB 量级），场景图 256 色量化，按键贴图按用途缩尺
