------------------------------------------------------------------------
 一、三十秒跑起来
------------------------------------------------------------------------

■ 方式 A：用 Godot 打开（正式工程，推荐）

  1. 下载 Godot Engine 4.7.1 stable（标准版即可，不需要 .NET 版）
       https://godotengine.org/download
  2. 启动 Godot → 点「导入」→ 选择本压缩包里的：
       game/project.godot
  3. 打开后按 F5 运行。

  ★ 工程不依赖任何外部素材文件。
    背景、立绘、特效、BGM、音效全部在运行时由代码生成，
    所以解压即可运行，绝不会出现「资源丢失 / 找不到文件」的报错。

■ 方式 B：不装 Godot，直接用浏览器试玩

  在压缩包根目录执行：
       python3 -m http.server 8080 --directory tools/preview
  然后浏览器打开：
       http://localhost:8080

  这是 Godot 工程的浏览器等价实现，读取的是同一份 story/*.avg 剧本，
  变量、章节结算、结局判定与 GDScript 版本逐行对应。
  适合快速试玩剧情、给策划校对文本。

■ 方式 C：导出 Android APK

  1. Godot 编辑器 → 编辑器 → 管理导出模板 → 下载 4.7.1 的模板
  2. 编辑器设置 → 导出 → Android：填好 Android SDK 路径与 debug keystore
  3. 项目 → 导出 → 选中已内置的「Android」预设 → 导出项目

  export_presets.cfg 已随包提供，内含 Android / Windows / Linux 三个预设，
  导入后在导出面板里直接能看到，不用自己新建。

  工程已按手机端配置：Mobile 渲染后端、触屏模拟鼠标、
  1280x720 基准 + canvas_items 拉伸 + expand 宽高比（横竖屏都不裁切）。

 三、包内有什么
------------------------------------------------------------------------

  game/            ← Godot 4.7.1 工程本体（用 Godot 打开这个目录）
    project.godot     工程配置（Mobile 渲染 / 触屏 / 自适应）
    main.tscn         主场景
    export_presets.cfg 导出预设（Android / Windows / Linux）
    autoload/         五个全局单例
      config.gd         16 项数值变量区间、10 个状态机键、角色表、阈值表
      game_state.gd     标记/道具/线索/四章结算/五结局判定
      story_engine.gd   .avg 剧本 DSL 解析器 + 运行时虚拟机
      audio_director.gd 全部音频运行时程序化合成（无需音频文件）
      save_system.gd    8 手动槽 + 自动存档 + 设置 + 跨周目数据
    src/
      art/              程序化美术：18 个场景背景、6 名角色立绘、19 种特效
      ui/               标题 / 游戏 / 结局界面 + 回想、线索、状态、存档、设置
    story/            ★ 剧本，9 个 .avg 文件 / 325 节点（策划可直接改）

  tools/
    validate_story.py   剧本静态校验（断链 / 死路 / 未知指令 / 可达性）
    check_gdscript.py   代码静态检查（括号 / 路径 / 单例 / 信号）
    simulate.py         运行时模拟器（随机通关 + 五结局可达性验证）
    preview/            浏览器试玩版（与工程共用同一份剧本）

  a.md ~ f.md      原始策划开发文档
  README.md        完整开发文档（DSL 语法、系统对照表、结局条件、扩展指引）
  快速开始.txt      本文件

 四、改剧本（不用碰代码）
------------------------------------------------------------------------

  剧本在 game/story/*.avg，纯文本，UTF-8。语法示例：

    == ch1_s1_a                    节点定义
    @bg classroom night            背景（变体：day/dusk/night/dark/rain/blood/fire）
    @bgm bgm_horror                音乐
    @sfx sfx_knock_pattern         音效
    @fx heartbeat 1.2              全屏特效
    @show liangye terrified left   立绘（角色 表情 位置）
    @set truth +2                  数值增减（按区间自动钳制）
    @flag flag_gave_up_roommate    剧情标记
    @item +item_page109            道具
    @clue clue_dont_answer         线索
    @note 别替我答到。             纸条弹窗
    @roster                        动态名单（内容随状态变化）
    @if truth>=15 ... @endif       条件分支
    @goto ch2_start                跳转
    @goto __ending__               按判定表分流结局

    liangye(fear)：我倒希望是。     角色台词
    > 他为什么不敢弯腰？            旁白强调
    教室里风扇嘎吱嘎吱地摇。         普通旁白

    * “你继续说。” -> ch1_s3_a      选项
        @set truth +2               缩进的 @ 行 = 该选项效果
    * [if flag_shenhe_name_full] “沈禾，是你吗？” -> ch2_door_d   条件显示
    * [lock item:item_roster_core] 把名单摊开 -> final_s3_c        不满足则灰显

  改完务必跑一遍校验（需要 Python 3）：

      python3 tools/validate_story.py    保证不会跳到不存在的节点
      python3 tools/simulate.py          保证没有死循环、没有全锁死的绝境

  同步到浏览器试玩版：
      cp game/story/*.avg tools/preview/data/
